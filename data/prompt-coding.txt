Implement a Python module, with no third-party dependencies, that parses a subset of the Prometheus text exposition format into a dictionary keyed by metric name. The module must be usable as a single import and must not perform any I/O itself: it accepts a string and returns a structure.

Support the following grammar. Comment lines beginning with a hash and blank lines are ignored. A metric may be preceded by TYPE and HELP comment lines, which should be captured rather than discarded. A sample line consists of a metric name, an optional label set in braces, a floating point value, and an optional timestamp. Label values are double quoted and may contain escaped quotes and escaped backslashes. Metric names and label names follow the usual Prometheus identifier rules. Histograms arrive as a family of samples whose names carry the _bucket, _count, and _sum suffixes, and whose buckets carry an le label whose value may be the literal +Inf; the parser should group these into a single histogram object rather than leaving them as unrelated metrics. Samples whose names carry the _created suffix should be attached to their parent metric instead of appearing as separate metrics.

Reject malformed input with a single exception type whose message names the offending line number and the reason, including at least: an unterminated label set, an unterminated quoted value, a value that does not parse as a float, a sample line for a family never declared, and a le bucket value that is neither a float nor +Inf.

Return only code. Use type hints throughout, give every public function a short docstring stating what it accepts and what it returns, and prefer plain dataclasses over dictionaries for the parsed structures.
